# 운영 매뉴얼

## 예배 준비

1. 해당 주 교회력과 순서지를 확인한다.
2. 예배 순서에 맞춰 제목, 담당자, 성경 본문, 찬양을 입력한다.
3. 찬양은 실제 순서대로 넣고, 필요한 곡 수만큼 추가한다.
4. 광고, 참고 화면, 이미지, 영상은 들어갈 순서에 맞춰 넣는다.
5. 본문, 인용 구절, 찬양 가사, 담당자 이름이 주보와 맞는지 확인한다.

## 예배 직전

1. 좌측 순서와 중앙 슬라이드의 순서가 같은지 확인한다.
2. 우측 미리보기와 실제 송출 화면을 확인한다.
3. 대기 화면, 첫 화면, 영상과 음향을 미리 점검한다.
4. 크로마키 예배는 초록 배경과 하단 자막이 정상인지 확인한다.
5. 변경한 내용은 저장한다.

## 예배 진행

1. 현재 송출 화면과 진행 순서를 수시로 확인한다.
2. 순서나 내용이 바뀌면 해당 예배에서 바로 수정하고 저장한다.
3. 영상이 재생되지 않으면 송출 화면에서 `Space`를 눌러 다시 재생한다.
4. 특송, 광고, 참고 화면은 실제 진행에 맞춰 넘긴다.

## 방송 전

1. 조명과 냉난방을 확인한다.
2. AVR, 음향 전원, 선풍기를 켠다.
3. 창고 장비를 켠 뒤 컴퓨터, A/V 믹서, 모니터, 카메라 조정기, 조명을 켠다.
4. 오늘 예배의 대기 화면과 첫 화면을 실제 출력으로 확인한다.
5. 카메라, A/V 믹서, 오디오 입력 상태를 확인한다.

## 방송 진행

1. 카메라 1은 설교대, 카메라 2는 무대, 카메라 3은 십자가와 본당 확인에 사용한다.
2. 찬양대 순서에는 카메라 3을 메인, 카메라 2를 서브로 사용한다.
3. A/V 믹서의 오디오 입력이 켜져 있는지 확인한다.
4. 화면과 실제 출력이 같은지 수시로 확인한다.
5. 예배 시간, 특송, 음향에 변동이 생기면 진행 담당자와 바로 확인한다.

## 예배 후

1. 송출을 종료하고 종료 화면이나 대기 영상을 확인한다.
2. 컴퓨터, A/V 믹서, 모니터, 카메라 조정기, 조명 순으로 일반 장비를 끈다.
3. 창고 장비, 선풍기, 음향 전원, AVR을 끈다.
4. 냉난방과 조명을 마무리한다.

## 상황별 안내

- 축도를 주기도문으로 바꿔야 할 때는 해당 순서에서 주기도문으로 변경한다.
- 이미지나 영상은 필요한 위치에 자유롭게 넣을 수 있다.
- 사용하지 않는 빈 화면은 지운다.
- 믹서 게인을 임의로 높이지 않는다. 48V는 콘덴서 마이크나 D.I.에만 사용한다.
- 장비 전원 순서와 위치는 실제 방송실 표기를 따른다.
