# 운영 매뉴얼

예배 입력과 방송 진행을 한 흐름으로 관리한다. 장비의 실제 위치와 스위치 표기가 바뀐 경우에는 이 문서보다 현장 표기를 우선한다.

## 예배 시간과 장소

### 주일

- 주일예배 1부: 오전 7:00, 1F 베데스다홀
- 주일예배 2부: 오전 8:50, 3·4F 본당
- 주일예배 3부: 오전 10:50, 3·4F 본당
- 유치부: 오전 10:50, 4F 유아유치부실
- 어린이부: 오전 10:30, 2F 교육관
- 청소년부: 오전 10:50, 1F 베데스다홀
- 청년부: 오후 1:10, 1F 베데스다홀
- 주일오후예배: 오후 1:20, 3·4F 본당

셋째 주에는 온세대 찬양예배를 진행한다. 주일이 다섯 번 있는 달은 넷째 주에 진행한다.

### 평일

- 수요예배(삼일예배): 수요일 오후 7:10, 3·4F 본당
- 금요예배(기획예배): 금요일 오후 8:00, 1F 베데스다홀 또는 3·4F 본당
- 첫째 주 금요예배: 월삭예배
- 둘째 주 금요예배: 금요기도회 또는 문화예배
- 셋째 주 금요예배: 연합예배(삼삼오오예배, 남성구역연합예배 등)
- 넷째 주 금요예배: 구역연합예배 또는 금요기도회

## 예배 입력

1. 해당 주 교회력, 주보, 순서지를 확인한다.
2. 예배 순서에 맞춰 제목, 담당자, 성경 본문, 찬양을 입력한다.
3. 찬양은 실제 진행 순서대로 넣고 필요한 곡 수만큼 추가하거나 삭제한다.
4. 광고, 참고 화면, 이미지, 영상은 실제 순서에 맞춰 필요한 위치에 넣는다.
5. 본문, 인용 구절, 가사, 담당자 이름이 주보와 같은지 확인한다.
6. 순서가 달라지거나 현장에서 변경되면 해당 예배에서 수정한 뒤 저장한다.

## 예배 직전

1. 좌측 순서와 중앙 슬라이드의 순서가 같은지 확인한다.
2. 우측 미리보기와 실제 송출 화면을 확인한다.
3. 대기 화면, 첫 화면, 영상과 음향을 미리 점검한다.
4. 크로마키 예배는 초록 배경과 하단 자막이 정상인지 확인한다.
5. 1부 시작 전에는 음향기기 리버브를 확인한다.
6. 변경한 내용이 저장됐는지 확인한다.

## 예배 진행

1. 현재 송출 화면과 실제 진행 순서를 수시로 확인한다.
2. 특송, 광고, 참고 화면은 실제 진행에 맞춰 넘긴다.
3. 영상이 재생되지 않으면 송출 화면에서 `Space`를 눌러 재생을 다시 시도한다.
4. 축도를 주기도문으로 바꿔야 할 때는 해당 순서에서 주기도문으로 변경한다.
5. 성경봉독 이후 그랜드피아노(GP) 볼륨을 -20으로 낮춘다.

## 방송 장비와 전원

### 주요 장비

- AVR(자동 전압 조정기): 유치부실 뒤 창고. 모든 기기보다 먼저 켠다.
- 음향기기, 조명기기: 유치부실 뒤 창고.
- 컴퓨터, A/V 믹서, 방송실 모니터, 카메라 조정기, 조명기: 방송실.
- 방송실 모니터는 방송실 좌측 리모컨으로 켜고 끈다.

### 예배 전: ON

1. 점등한다.
2. 냉·난방기를 가동한다.
3. 창고 AVR을 켠다.
4. 방송실 좌측 `[1-음향전기]` 스위치를 켠다.
5. 선풍기를 켠다.
6. 창고의 음향기기와 조명기기를 켠다.
7. 컴퓨터, A/V 믹서, 방송실 모니터, 카메라 조정기, 조명기를 켠다.
8. 예배 전후 영상과 음악을 재생한다.

### 예배 후: OFF

1. 종료 화면 또는 예배 후 영상과 음악을 재생한다.
2. 조명기, 카메라 조정기, 방송실 모니터, A/V 믹서, 컴퓨터 순으로 끈다.
3. 창고의 음향기기와 조명기기를 끈다.
4. 선풍기를 끈다.
5. 방송실 좌측 `[1-음향전기]` 스위치를 끈다.
6. 창고 AVR을 끈다.
7. 냉·난방기를 종료하고 소등한다.

## 카메라

본당에는 카메라가 세 대 있다. `[Camera]`로 카메라를 선택하고 조이스틱으로 움직인다. `[Position]`으로 저장된 위치를 불러오거나 저장한다. 새 위치를 저장할 때는 해당 `[Camera]` 버튼을 10초간 누른 뒤 조이스틱으로 조정하고 `[Position]` 번호를 누른다.

### 포지션

- 카메라 1: `1-1` 설교대 일반 배율로 상시 사용한다. 설교자가 장신이면 `1-2` 설교대 축소 배율을 쓴다.
- 카메라 2: `2-1` 무대 전경, `2-2` 사회자석, `2-3` 찬양대 지휘자·반주자, `2-4` 무대와 십자가 전경(3부 결단기도)을 쓴다.
- 카메라 3: `3-1` 본당 십자가(통성기도), `3-2` 본당 복도(설교자·성도 재석 확인), `3-3` 찬양대석 전경(찬양대 특송)을 쓴다.

카메라 1은 설교대, 카메라 2는 무대, 카메라 3은 십자가와 본당 확인에 주로 사용한다. 찬양대 순서에는 카메라 3을 메인, 카메라 2를 서브로 사용한다.

## 화면과 송출

### A/V 믹서

A/V 믹서는 카메라 세 대와 컴퓨터 듀얼 모니터 화면을 송출한다. 오디오는 컴퓨터로 보내며 `[AUDIO]` 묶음의 `[IN]` 버튼을 확인한다. 녹화를 위해 상시 켜 둔다.

### 예배 전후 화면

예배 전후에는 대기 영상을 재생한다. Windows에서 팟플레이어를 쓸 때는 `Windows` + 화살표로 듀얼 모니터로 옮긴 뒤 `Alt` + `Enter`로 전체 화면을 실행한다.

예배 PPT는 예배 전에 `F5`로 슬라이드 쇼를 실행한다. 크로마키(`#00FF00`) 화면이 송출되지 않도록 슬라이드 쇼 위에 영상을 틀거나 A/V 믹서의 `[PREVIEW]`를 켠다.

본당 예배는 교내 3층·1층 텔레비전에 송출한다. 녹화와 외부 송출은 OBS Studio를 사용한다. 실제 공개·비공개 설정은 그 주의 방송 계획을 따른다.

## 음향

SoundCraft SI Impact 3.0 믹서는 필요한 기능만 조작한다. 볼륨이 작더라도 게인을 임의로 올리지 않는다. 하울링 위험이 있다. 48V는 콘덴서 마이크 또는 D.I.에만 켠다. 이미 세팅된 값은 유지한다.

- ST 1: 보컬 리버브
- ST 2: 건반 리버브
- ST 3: 딜레이

## 진행 중 연락

방송 담당자는 예배 변동과 비상 상황에 대비해 3층 교역자와 바로 연락할 수 있어야 한다. 다음 상황은 확인 후 바로 반영한다.

- 예배 시작 시간 변경
- 음향 문제, 음량 또는 효과 조절 요청
- 교내 송출 문제
- 특송 곡 또는 순서 변경

## 마무리 확인

- 송출을 종료하고 실제 출력이 종료 화면 또는 대기 화면인지 확인한다.
- 사용하지 않는 빈 화면은 삭제한다.
- 이미지와 영상은 필요한 위치에 자유롭게 넣을 수 있다.
- 장비 전원 순서와 위치는 현장 표기를 따른다.
