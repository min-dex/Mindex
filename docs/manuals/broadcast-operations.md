# 방송 매뉴얼

## 예배 전

1. 조명과 냉난방을 확인한다.
2. AVR, 음향 전원, 선풍기를 켠다.
3. 창고 장비 다음으로 컴퓨터, A/V 믹서, 모니터, 카메라 조정기, 조명을 켠다.
4. 오늘 예배의 대기 화면과 첫 화면을 실제 출력으로 확인한다.
5. 카메라, A/V 믹서, 오디오 입력 상태를 확인한다.

## 진행 중

1. 카메라 1은 설교대, 카메라 2는 무대, 카메라 3은 십자가와 본당 확인에 사용한다.
2. 찬양대 시에는 카메라 3을 메인, 카메라 2를 서브로 사용한다.
3. A/V 믹서의 오디오 입력이 켜져 있는지 확인한다.
4. 화면과 실제 출력이 같은지 수시로 확인한다.
5. 예배 시간, 특송, 음향에 변동이 생기면 진행 담당자와 바로 확인한다.

## 예배 후

1. 종료 화면 또는 대기 영상을 확인한다.
2. 컴퓨터, A/V 믹서, 모니터, 카메라 조정기, 조명 순으로 일반 장비를 끈다.
3. 창고 장비와 선풍기, 음향 전원, AVR을 순서대로 끈다.
4. 냉난방과 조명을 마무리한다.

## 주의

- 믹서 게인을 임의로 높이지 않는다. 하울링 위험이 있다.
- 48V는 콘덴서 마이크 또는 D.I.에만 사용한다.
- 장비 과열 방지를 위한 선풍기 상태를 확인한다.
- 장비 전원 순서와 위치는 실제 방송실 표기를 따른다.

## 연락이 필요한 경우

- 예배 시작 시간 변경
- 음향 문제 발생
- 음량이나 음향 효과 조절
- 교내 송출 문제 발생
- 특송 곡 변경
