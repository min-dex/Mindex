# 방송 운영 가이드

## 현장 원칙

방송실 장비의 전원 순서와 위치는 실제 장비 라벨이 최종 기준이다. 아래 절차는 2026년 9월 이관 당시 운영 흐름이며, 장비 교체나 배선 변경이 있으면 현장 확인 후 갱신한다.

## 예배 전

1. 조명과 냉난방을 확인한다.
2. 창고 AVR, 음향 전원, 냉각용 선풍기를 순서대로 켠다.
3. 창고 장비 다음으로 컴퓨터, A/V 믹서, 모니터, 카메라 조정기, 조명을 켠다.
4. MINDEX에서 오늘 예배를 열고, 대기 화면과 첫 슬라이드를 우측 미리보기와 실제 출력에서 확인한다.
5. 카메라, A/V 믹서, 오디오 입력 상태를 확인한다. 게인과 48V는 임의로 바꾸지 않는다.

## 진행 중

1. 카메라 1은 설교대, 카메라 2는 무대, 카메라 3은 십자가·본당 확인이라는 기본 역할을 지킨다.
2. 찬양대 시에는 카메라 3을 메인, 카메라 2를 서브로 사용한다.
3. A/V 믹서의 오디오 입력이 켜져 있는지 확인한다.
4. MINDEX 프레젠터의 현재 슬라이드와 실제 출력이 같은지 수시로 확인한다.
5. 영상과 음향 이상, 특송 변경, 시작 시간 변동은 즉시 교역자 또는 진행 담당자와 확인한다.

## 예배 후

1. 종료 화면 또는 대기 영상을 확인한다.
2. 컴퓨터, A/V 믹서, 모니터, 카메라 조정기, 조명 순으로 일반 장비를 끈다.
3. 창고 장비와 선풍기, 음향 전원, AVR을 순서대로 끈다.
4. 냉난방과 조명을 마무리한다.

## 주의

- 믹서 게인을 임의로 높이지 않는다. 하울링 위험이 있다.
- 48V는 콘덴서 마이크 또는 D.I.에만 사용한다.
- 장비 과열 방지를 위한 선풍기 상태를 확인한다.
- 기존 PPT/팟플레이어 절차는 원문 보존본에 남겨 두되, 현재 예배 화면 운용은 MINDEX 프레젠터를 우선한다.
