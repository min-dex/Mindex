# 예배 운영 가이드

## 기준

MINDEX의 각 예배는 독립된 저장 단위다. 찬양 DB나 말씀 DB에서 불러온 뒤에도, 해당 예배에 배치된 슬라이드와 입력값이 그 예배의 실행본이다. 원본 DB는 다시 불러오기와 정정에 쓰되 이미 준비된 다른 예배의 내용을 바꾸지 않는다.

## 준비

1. 교회력에서 날짜와 예배 유형을 확인하고 해당 예배를 연다.
2. 순서별 입력창에서 제목, 담당, 본문, 찬양을 입력한다.
3. 찬양은 필요한 개수만큼 추가한다. 번호는 표시 순서일 뿐 고정된 개수 제한이 아니다.
4. DB에서 곡이나 본문을 불러온 경우에도, 예배에 만들어진 슬라이드가 실제 송출 대상인지 확인한다.
5. 이미지, 영상, 참고화면처럼 예외 성격의 자료는 해당 엘리멘트 안에 넣어 예배 데이터와 함께 보존한다.

## 검증

1. 좌측 순서, 중앙 슬라이드, 우측 미리보기의 제목과 순서를 비교한다.
2. 본문, 인용 구절, 찬양 가사, 담당자 표기가 오늘 예배와 맞는지 확인한다.
3. 불필요한 빈 슬라이드는 제거한다. 대기 화면을 포함한 모든 엘리멘트는 동일한 빈 슬라이드 규칙을 따른다.
4. 크로마키 예배는 실제 송출 화면에서 초록 배경과 하단 바를 확인한다.
5. 저장 상태가 깨끗한지 확인한 뒤 `저장` 또는 `Cmd/Ctrl+S`를 사용한다.

## 송출

1. 송출 전 우측 미리보기와 프레젠터의 현재 슬라이드 번호가 같은지 확인한다.
2. 송출 시작 후 첫 화면, 영상 재생, 오디오, 다음 슬라이드 전환을 확인한다.
3. 영상이 자동 재생되지 않으면 프레젠터에서 Space를 눌러 재생을 다시 시도한다.
4. 예배 중 내용 변경은 해당 예배의 입력창에서 수정하고 저장한다. 다른 예배나 원본 DB를 직접 고쳐 현재 예배를 바꾸지 않는다.

## 예배 후

1. 송출을 종료한다.
2. 필요하면 예배별 source text와 슬라이드 구성을 보존해 다음 주 준비의 출발점으로 쓴다.
3. 원본 찬양이나 말씀의 오탈자는 DB에서 정정하되, 이미 진행된 예배의 실행본은 의도 없이 바꾸지 않는다.

## 예외 처리

- 축도를 주기도문으로 바꾸는 것처럼 예배학적 예외는 해당 엘리멘트의 선택으로 남긴다.
- 첨부 이미지나 영상은 일반 텍스트 엘리멘트와 섞어 배치할 수 있다.
- 내용이 비어 있는 순서는 임의의 이전 값으로 채우지 않는다. 빈 상태 자체도 오늘 예배의 의도일 수 있다.
