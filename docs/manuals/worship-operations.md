# 예배 매뉴얼

## 예배 준비

1. 해당 주 교회력과 순서지를 확인한다.
2. 예배 순서에 맞춰 제목, 담당자, 성경 본문, 찬양을 입력한다.
3. 찬양은 실제 순서대로 넣고, 필요한 곡 수만큼 추가한다.
4. 광고, 참고 화면, 이미지, 영상은 들어갈 순서에 맞춰 넣는다.
5. 본문, 인용 구절, 찬양 가사, 담당자 이름이 주보와 맞는지 확인한다.

## 예배 직전

1. 좌측 순서와 중앙 슬라이드의 순서가 같은지 확인한다.
2. 우측 미리보기와 실제 송출 화면을 확인한다.
3. 대기 화면, 첫 화면, 영상과 음향을 미리 점검한다.
4. 크로마키 예배는 초록 배경과 하단 자막이 정상인지 확인한다.
5. 변경한 내용은 저장한다.

## 예배 중

1. 현재 송출 화면과 진행 순서를 수시로 확인한다.
2. 순서나 내용이 바뀌면 해당 예배에서 바로 수정하고 저장한다.
3. 영상이 재생되지 않으면 송출 화면에서 `Space`를 눌러 다시 재생한다.
4. 특송, 광고, 참고 화면은 실제 진행에 맞춰 넘긴다.

## 예배 후

1. 송출을 종료한다.
2. 다음 예배 준비에 필요한 메모나 자료가 있으면 해당 예배에 남긴다.
3. 찬양 가사나 성경 본문의 오탈자는 확인 후 정리한다.

## 상황별 안내

- 축도를 주기도문으로 바꿔야 할 때는 해당 순서에서 주기도문으로 변경한다.
- 이미지나 영상은 필요한 위치에 자유롭게 넣을 수 있다.
- 사용하지 않는 빈 화면은 지운다.
