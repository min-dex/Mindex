# MINDEX 운영 매뉴얼

이 디렉터리는 기존 Notion 운영 문서를 MINDEX 저장소로 이관한 기준 위치다.

## 문서의 역할

- `notion-source/`: Notion 삭제 전 대조할 수 있는 원문 보존본이다. 사실관계가 바뀌어도 원문을 덮어쓰지 않는다.
- `worship-operations.md`: 예배 입력, 검증, 송출을 위한 현재 운영 절차다.
- `broadcast-operations.md`: 방송실 장비와 현장 송출 절차다.

예배 날짜, 시간, 담당자, 순서, 찬양, 성경 본문처럼 매주 변하는 정보는 이 문서가 아니라 MINDEX의 예배 데이터가 기준이다. 문서는 `how to operate`, 예배 데이터는 `what happens today`를 맡는다.

## 갱신 규칙

1. 절차나 장비가 바뀌면 운영 문서를 먼저 고친다.
2. Notion에서 옮긴 원문이 더 필요하면 새 보존본을 날짜와 함께 추가한다. 기존 보존본은 수정하지 않는다.
3. 현장 확인이 필요한 장비 이름, 위치, 전원 순서는 실제 방송실 표기와 대조한 뒤만 바꾼다.
