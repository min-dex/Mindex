# 청년부 주보

## 저장 구조

예배 한 건에 주보 한 건을 연결한다. 별도 발행본·템플릿 버전 테이블은 만들지 않는다.

`mindex_bulletins`의 데이터는 두 묶음이다.

- `content`: 주보 문구, 일정·위원표 표시 월, 인쇄용 순서 정리 선택.
- `layout`: 자동 배경 모드 또는 공용 배경 파일명, 프레임별 위치·크기·글자 크기·정렬·표시 여부.

`service_id`로 예배를 참조하고, `revision`과 `updated_at`은 저장 충돌 확인용이다.
예배 순서·찬양·본문·대표기도·교회 일정은 기존 DB에서 읽는다.
주보 저장이 예배나 찬양 원본을 변경하지 않는다.

## 배포 상태와 적용 순서

2026-09-23 사용자가 운영 DB에 테이블 추가 SQL을 적용했다. 필수 열의 REST 읽기와
실제 청년부 예배의 편집창·2쪽 미리보기·공용 배경 목록 연결을 확인했다.

1. [테이블 추가 SQL](../migrations/2026-09-23-bulletin-content-layout.sql)을 운영 DB에 적용한다.
2. 테이블·권한·revision 트리거를 확인한다.
3. 해당 클라이언트를 배포한다. 테이블 없이 배포하면 편집창은 DB 연결 실패를 표시한다.

쓰기 역할은 기존 공유 Worship 클라이언트와 동일한 `anon`, `authenticated`다.
관리자 인증 강화 스크립트 적용 시 다른 관리 테이블과 함께 authenticated 쓰기로 제한한다.
클라이언트는 서비스 키를 사용하지 않는다.

## 저장·복구

- 저장 버튼과 Ctrl/Cmd+S는 내용과 양식을 한 번에 DB에 저장한다.
- 읽은 revision이 현재 DB와 같을 때만 수정한다. 동시 생성·수정 충돌은 덮어쓰지 않는다.
- 입력 중 내용은 브라우저에 복구본으로 남긴다. DB 저장 성공과 구분해서 상태를 표시한다.
- 기존 로컬 초안과 날짜별 공통 문구 설정은 삭제하지 않는다.
- DB에 주보가 없으면 기존 로컬 초안을 가져와 저장할 수 있다.
- DB 주보가 있으면 DB를 먼저 연다. 기존 브라우저 초안은 별도 복구 버튼으로 불러온다.
- 충돌 후 DB 다시 불러오기 전에 현재 수정본을 복구본으로 남긴다.
- 이미지 데이터는 주보 DB에 복제하지 않는다. 기기에서만 등록한 배경은 다른 기기에서도
  같은 이름으로 등록되어 있어야 하며, 없으면 안내하고 출력을 막는다.

## 원본과 사용자 선택

- 배경은 기존 MINDEX 배경 목록의 실제 등록/기본 자산 전체를 사용한다.
  여섯 개만 골라둔 목록·별칭은 제거했다.
- 신규 주보는 날짜·부서에 따른 자동 배경으로 시작한다. Presenter의 기존 배경 선택 함수를 공유하며 절기 배경을 우선한다. 자동 모드는 DB에도 그대로 저장한다.
- 기존 초안에서 직접 선택한 배경과 배경 없음은 보존한다. 양식의 배경에서 자동으로 전환할 수 있다.
- 신규 옵션에서 임의의 흰 바탕·짙은 테두리 테마를 제거했다. 기존 선택값은 복구를 위해 읽을 수 있다.
- 일부 배경에만 적용하던 흰 패널 88% 불투명도 규칙을 제거했다.
- 광고를 환영·정기 안내로 자동 분류하지 않고 원문과 번호를 보존한다.
- 인쇄용 순서 생략·합치기는 기본으로 하지 않는다. 사용자가 선택한 경우에만 적용한다.
  영상·이미지·공백 등 비텍스트 송출 자산과 원본에서 숨긴 항목은 예배 순서 텍스트에 넣지 않는다.
- 과거 교회명·명단·기도 모임 안내는 자동으로 채우지 않는다.
  '기존 주보 문구 불러오기'를 누르면 빈 칸에만 참고 문구를 넣고 현재 정보인지 확인하도록 안내한다.
- 발행 호수는 확인된 과거 날짜만 사용하고 미래 값을 임의 계산하지 않는다.
- 좌표 2.5mm, 글자 크기 2.5pt 단계와 A4 접지선 148.5mm는 수치 정돈 요청에 따라 유지한다.

## 출력·검증

A4 가로 두 페이지를 SVG로 렌더링하고 메모리 내 인쇄 iframe을 사용한다.
원본 폰트 Freesentation과 기존 배경 자산을 사용한다. 영역 넘침, 원본/자산 읽기 실패 시
인쇄를 막는다. 출력에는 편집 UI가 들어가지 않는다.

검증 파일:

- `tests/test_bulletin.cjs`: 원문 보존, 순서 정리 선택, 내용/양식 직렬화, 날짜별 참고 문구.
- `tests/test_bulletin_persistence.cjs`: 실제 DB adapter의 revision 조건, 충돌·권한·스키마 오류.
- `tests/smoke_bulletin.cjs`: 편집·저장·충돌·복구·브라우저 초기화 후 DB 복원·공용 배경·2쪽 PDF.

원본 조사 근거는 [72개 주보 조사](young-adult-bulletin-archive-review.md)를 참고한다.
운영 DB에 테스트 데이터를 쓰지는 않았다. 충돌·저장 실패·브라우저 초기화 후 복원은
오프라인 통합 검사로 검증했다.


## 2026-09-24 코드 점검

- 복구본 저장 실패는 DB 저장 오류와 분리한다. 용량 부족/접근 차단 시에도 DB 읽기와 저장을 계속한다.
- DB 다시 불러오기는 메모리에 현재 수정본을 보존한다. 브라우저 저장 실패가 다시 불러오기를 중단하지 않는다.
- 복구본은 허용된 내용/설정/프레임 값만 읽고 DB revision과 예배 ID는 복구본에서 가져오지 않는다.
- 복구본에 기록한 시각으로 최신 초안을 선택한다. 손상된 JSON이나 프레임 구조는 DB 로딩을 막지 않는다.
- 본문형 예배 항목은 제목뿐 아니라 저장된 body를 읽는다. 순서 간추리기를 끄면 고백 전문이 유지된다.
- 안쪽 교회명도 입력한 교회명 데이터를 사용한다. 별도 고정 문자열을 제거했다.
- 출력에서 숨긴 영역의 넘침은 인쇄를 막지 않는다. 출력할 영역의 가로/세로 넘침과 너무 좁은 열은 차단한다.
- 인쇄는 한 번에 하나만 준비하고, 편집창이 닫히면 인쇄 준비를 취소한다.

브라우저 통합 검사에서 QuotaExceededError와 SecurityError, 손상/오래된 복구본,
DB 저장 실패/충돌, 숨긴 영역, 좁은 열, 중복 인쇄와 인쇄 중 창 닫기를 재현했다.
운영 DB에는 점검용 데이터를 쓰지 않았다. 사용자의 실제 브라우저에서 발생한 저장소 오류 종류는 확인하지 못했다.

## 독립 편집 탭

주보 버튼은 예배 화면을 유지한 채 별도 주보 탭을 연다. 같은 예배의 주보 탭이 이미 있으면 해당 탭을 활성화한다. 탭 제목은 부서와 예배 날짜를 표시하며 URL의 `bulletin` 값으로 복원한다. 탭 전환 중 저장 전 내용과 실행 취소 기록은 탭별 메모리에서 유지한다. 탭을 닫으면 기존 브라우저 복구본과 DB 저장 규칙을 따른다.

## 독립 주보 섹션

왼쪽 주보 메뉴는 예배와 동등한 독립 모듈(`bulletin`)이다. 청년부 주보의 날짜 목록에서 편집기를 열며 편집 탭 제목은 `청년부 주보`로 표시한다. 예배 화면의 주보 버튼도 같은 모듈로 연결한다. 예배 자료는 연결된 예배 ID로 읽고, 주보 문구·양식은 기존 주보 DB에 따로 저장한다. 이전 Presenter 주보 주소도 독립 주보 모듈로 연다.
